# Swift Linux Foundation

Use this organization when you need a Linux Foundation specification in Swift: [swift-linux-standard](https://github.com/swift-linux-foundation/swift-linux-standard) for the Linux platform interface, or [swift-model-context-protocol](https://github.com/swift-linux-foundation/swift-model-context-protocol) for the Model Context Protocol types. Each follows its source document as literally as possible. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift Linux Foundation is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the Linux Foundation.
