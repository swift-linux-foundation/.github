# Swift Linux Foundation

Swift implementations of Linux Foundation specifications — a per-authority organization of [swift-standards](https://github.com/swift-standards), Layer 3 of the [Swift Institute](https://github.com/swift-institute) ecosystem.

## What this is

This organization hosts [swift-linux-standard](https://github.com/swift-linux-foundation/swift-linux-standard), the Linux platform interface, and [swift-model-context-protocol](https://github.com/swift-linux-foundation/swift-model-context-protocol), the Model Context Protocol specification types. Each package implements its source document as literally as possible, with parsing, validation, and formatting enforced by Swift's type system. Where several specifications govern one subject, the unifying `swift-*-standard` package lives in [swift-standards](https://github.com/swift-standards).

> Swift Linux Foundation is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the Linux Foundation.

Browse the organization's [repositories](https://github.com/swift-linux-foundation?tab=repositories) for current package locations.

Contributions are welcome via pull request.
